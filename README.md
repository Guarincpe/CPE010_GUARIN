## Course Objectives

> This course aims to teach and build core data structures in C++, such as Abstract Data Types, Linked Lists, Stacks, Queues, Trees, and Graphs. Along the way, mathematical methods are used to judge how efficient the different algorithms are, including the typical operations performed on each data structure. Students then apply what they have learned by writing their own C++ programs and testing how well they perform on real systems.

---

## 🍇 Course Intended Learning Outcomes

1. Apply fundamental data structures and techniques to solve engineering-related problems through algorithm design.
2. Design efficient algorithms and analyze their complexity.
3. Build efficient algorithms based on selected data structures using good programming styles in C++
